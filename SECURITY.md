# Security policy

## Supported versions

Security fixes target the latest released version of AimSpan. Older releases are not supported; reproduce issues on the latest release when possible.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Asxing/aimspan/security/advisories/new) for this repository: open the **Security** tab and choose **Report a vulnerability**. Do not disclose an unpatched vulnerability in a public issue or pull request.

Include the affected AimSpan version, macOS version, expected and observed behavior, potential impact and a minimal synthetic reproduction. Do not attach credentials, real transcripts, user databases or unredacted screenshots. Maintainers can discuss any additional evidence privately in the advisory.

Private reporting must be enabled by the repository owner before public release. If the reporting form is unavailable, do not post vulnerability details publicly; a public issue may simply ask the maintainer to enable private reporting.

See [Security and data handling](docs/SECURITY.md) for AimSpan's authority boundaries, read-only native sources, local storage and recovery design.
