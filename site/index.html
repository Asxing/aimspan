For people who run many Claude Code and Codex sessions

Keep your train of thought while agents work.

Long agent turns break your focus. AimSpan holds the thread.

See what is active

Running and waiting sessions from Claude Code and Codex in one list. A session stays “waiting” until you mark it handled or send a new prompt in its native app.

⌘ ⇧ Space

Capture ideas in seconds

Press the shortcut, type, hit Enter. Save an idea to the session it belongs to or the inbox, and get back to what you were doing.

Catch up when you switch back

A catch-up card brings results and recent activity together with your saved ideas. Click to copy ideas and open the native app. You paste and send them yourself.

How it works

  1. 1

    Install and open

    AimSpan finds sessions in your local Claude Code and Codex records. No hooks to install or agent configuration to change.

  2. 2

    Keep working as usual

    Prompt agents in the apps you already use. Glance at the menu bar or floating bubble to see which sessions need you.

  3. 3

    Switch back with context

    Open the catch-up card, read what happened, and bring your ideas back. You decide what to send.

Local only.
Read only.

  • Reads ~/.claude and ~/.codex read-only. Never writes to them, installs hooks, or changes agent configuration.
  • No model calls, no account, no telemetry. Your ideas stay on your Mac, stored exactly as you wrote them.
  • Reads bounded, redacted observations without keeping a full transcript copy.
  • Never types into or sends to an agent. Bringing ideas back only copies text and opens the native app after your click. You paste and send.
  • Open source under the MIT License. You can read every line.

FAQ

macOS says the app cannot be verified

Early builds are ad-hoc signed and not notarized. Right-click AimSpan.app, choose Open, then confirm Open. Downloads appear on GitHub Releases when available; if there is no release asset yet, follow the source build instructions in the GitHub README.

Which agents are supported?

Claude Code in the Claude desktop app’s Code tab, CLI, and VS Code; and Codex in its desktop app, CLI, and VS Code. AimSpan reads their local records. Native formats can change, and exact session opening still needs real-app verification.

Windows or Linux?

AimSpan is macOS only.
