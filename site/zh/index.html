一眼看清活跃会话

Claude Code 与 Codex 中运行中、等你的会话，都放在一个列表里。会话会一直保持“等你”，直到你标记“已处理”，或在原 App 中发出新指令。

⌘ ⇧ Space

随手记下，不打断思路

按快捷键，写下想法，回车保存。用快捷记录把想法记到对应会话或收件箱，然后继续手头的事。

切回来，顺着往下做

衔接卡把执行结果、最近动态和你记下的想法放在一起。点击带回，就会复制想法并打开原 App；粘贴和发送由你完成。

使用方式

  1. 1

    装好，打开

    AimSpan 从本机的 Claude Code 与 Codex 记录中发现会话。不用安装 Hook，也不用改 Agent 配置。

  2. 2

    照常在原 App 里工作

    继续用熟悉的工具给 Agent 发指令。看一眼菜单栏或悬浮气泡，就知道哪些会话需要你。

  3. 3

    带着上下文切回来

    打开衔接卡，看过刚才的进展，再把想法带回去。下一步发什么，始终由你决定。

仅在本机。
原生记录只读。

  • 只读 ~/.claude 与 ~/.codex，绝不写入，不安装 Hook，也不改 Agent 配置。
  • 不调用模型，不用注册账户，没有遥测。想法原样保存在你的 Mac 上。
  • 只读取限定范围内的记录并做脱敏，不保留完整对话副本。
  • 不会代你输入或向 Agent 发送消息。只有你点击带回时，才复制文字并打开原 App；粘贴和发送由你完成。
  • 以 MIT 许可开源，每一行代码都可以查看。

常见问题

macOS 提示无法验证这个 App，怎么办？

早期版本采用临时签名（ad-hoc），尚未经过 Apple 公证。请右键点击 AimSpan.app，选择打开，然后再次确认打开。有可下载的版本时，会放在 GitHub Releases；如果暂时没有安装包，可以按 GitHub README 的说明从源码构建。

支持哪些 Agent？

支持 Claude Code（Claude 桌面 App 的 Code 页签、CLI、VS Code）和 Codex（桌面 App、CLI、VS Code），通过它们的本地记录读取会话。原生记录格式可能变化；能否精确打开原会话，仍需在真实 App 中验证。

支持 Windows 或 Linux 吗？

AimSpan 目前仅支持 macOS。
